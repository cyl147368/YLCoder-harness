# 命令清理验收任务

仅负责 CLI tools 包中新建的包私有 CommandProcessCleanup.java 和 CommandProcessCleanupTest.java。不要修改 WorkspaceTools、其他测试、文档或运行 Maven。其他成员也在工作；不要回退他们的修改。负责人整合并串行验证。

为 run_command 实现有时间上限、尽力执行的进程清理工具。枚举后代进程和关闭管道绝不能阻塞调用线程或直接进程终止。审阅 StdioMcpClient 已有清理修复。保留调用线程中断状态。针对后代枚举卡住、关闭卡住以及直接终止，提供确定性的模拟进程测试。清理范围保持适度，不重构共享 MCP。暴露小型包私有静态 API，并报告预期集成方式。不要声称保证整个进程树终止。本文件是权威指派。

集成要求：提供 `stop(Process)` 和 `closePipes(Process)`（或报告替代 API）。某些 JDK 上，直接销毁进程也可能等待已被阻塞的管道监视器；必要时也隔离该操作。后代枚举放到独立守护线程，直接终止前只给予短且有上限的先行时间，以保留正常进程树清理。负责人在启动时异步关闭 stdin，绝不在调用线程路径同步关闭管道。
